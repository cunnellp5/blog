I was under the impression i would use [cdn.jsdelivr](https://www.jsdelivr.com/), but when saving images to a GitHub repo they have raw img files. So here's my first test with a free image hosted service.

Steps:
1. create repo
2. heavily compress and reduce the size of the img - I used [squoosh](https://squoosh.app/)
3. save it to the root of the repo and push
4. right click and open image in a new tab then use the url
