I was under the impression i would use cdn.jsdelivr, but when saving images to a github repo they have raw img files. So here's my first post with a free image hosted service.

Steps:
1. create repo
2. heavily compress and reduce the size of the img
3. save it to the root of the repo and push
4. right click and open image in a new tab then use the url
